# AgriTech - Machine Learning & Vision Service

The computer vision and disease diagnostics microservice for the **Precision AgriTech Platform**, built with **Python** and **FastAPI**.

## Overview

This service handles foliage image analysis and leaf pathology diagnostics:

- **Leaf Disease Classification**: Classifies plant health using models trained on the PlantVillage dataset (12 classes across Tomato, Potato, Corn, Apple).
- **Low-Latency Inference**: Runs lightweight CNN models (MobileNetV3-Small / EfficientNet-B0) exported to ONNX format.
- **RESTful Diagnostics API**: Ingests multipart image uploads and returns predicted disease, confidence score, pathogen type, agronomic advisory, and class probabilities.
- **LIVE / STUB Dual Mode**: Operates with a full ONNX model (ML-102 + ML-103 complete) or gracefully in STUB mode when the model artifact is absent.

## Prerequisites

- Python 3.10+
- [`uv`](https://github.com/astral-sh/uv) (recommended) **or** `pip`

## Getting Started

### Option A — uv (recommended)

```powershell
# Install uv if not already installed
pip install uv

# Create virtual environment and install dependencies
uv venv
uv pip install -e ".[dev]"

# Activate
.\.venv\Scripts\Activate.ps1     # Windows
source .venv/bin/activate         # macOS/Linux
```

### Option B — pip (legacy)

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install pytest pytest-asyncio anyio httpx   # for tests
```

## Running the Inference Server

```powershell
# With uvicorn directly (development)
uvicorn main:app --reload --host 0.0.0.0 --port 8000

# Or via python entrypoint
python main.py
```

- **Swagger UI**: `http://localhost:8000/docs`
- **Liveness probe**: `GET http://localhost:8000/health/live`
- **Readiness probe**: `GET http://localhost:8000/health/ready`
- **Leaf Classification**: `POST http://localhost:8000/api/v1/classify-leaf`

## Configuration

Create a `.env` file in `ml-service/` to override defaults:

```env
# Path to ONNX model (generated by TODO-103)
ONNX_MODEL_PATH=models/agritech_classifier.onnx

# CORS origins (comma-separated list in JSON array format)
CORS_ORIGINS=["http://localhost:5173"]

# Enable debug logging
DEBUG=false
```

## LIVE vs STUB Mode

| Condition | Mode | `model_loaded` field |
|-----------|------|---------------------|
| `models/agritech_classifier.onnx` exists and is valid | **LIVE** | `true` |
| Model file absent or cannot be loaded | **STUB** | `false` |

In **STUB** mode the service returns deterministic dummy probabilities so the full
pipeline (validation, response shaping, advisory generation) can be tested
independently of ML-102 / ML-103 completion.

## Placing the ONNX Model (after ML-103 is complete)

```powershell
# Create the models directory
mkdir models

# Copy the exported model here
copy path\to\agritech_classifier.onnx models\agritech_classifier.onnx
```

Restart the service — it will automatically switch to LIVE mode.
